访问地址：http://localhost:8765

## 功能说明

### 1. 会话管理

- **会话列表**：左侧边栏显示所有会话
- **搜索**：支持按名称或 ID 搜索会话
- **新建会话**：点击 "+ New" 创建
- **切换会话**：点击会话名称切换

### 2. 聊天功能

- **发送消息**：在输入框输入，按 Enter 发送
- **换行**：Shift + Enter
- **Markdown 支持**：支持标题、列表、粗体等格式
- **工具调用显示**：执行工具时显示 `[执行工具: xxx]`

### 3. 定时任务 (Cron)

- **查看任务**：列表显示所有定时任务
- **创建任务**：点击 "Add" 添加新任务
- **编辑任务**：点击 "Edit" 修改
- **删除任务**：点击 "Delete" 删除
- **触发任务**：点击 "Trigger" 立即执行
- **启用/禁用**：点击 "Enable"/"Disable"

#### 任务字段

| 字段 | 说明 |
|------|------|
| Name | 任务名称 |
| Schedule | Cron 表达式（如 `0 9 * * *`） |
| Description | 任务描述（将作为用户输入触发 Agent） |
| Agent | 使用的 Agent |
| Session | 目标会话 ID |

### 4. 设置 (Settings)

- **Default Agent**：默认使用的 Agent
- **Commands**：CLI 命令参考
- **API Endpoints**：API 接口参考
- **Workspace**：数据目录结构说明
